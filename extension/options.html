fork-scout settings

Everything works with nothing set up. These are optional extras.

GitHub token (optional)

Without a token GitHub allows about 60 requests an hour, enough for small repos. A token raises that. Use a fine-grained token with read-only access to public repositories. Never use a token that can write.

Stored only in this browser. Sent only to api.github.com.

AI review (coming next)

Plain-English cards and an AI second opinion. When this is off, results are labelled "pattern scan only". The scan always runs, and a serious finding blocks copying whatever the AI says.
