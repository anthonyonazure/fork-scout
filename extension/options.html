fork-scout settings

Everything works with nothing set up. These are optional extras, and each one is stored only in this browser.

GitHub token for reading (optional)

Without a token GitHub allows about 60 requests an hour, enough for small repos. A token raises that. Use a fine-grained token with read-only access to public repositories. Never use a token that can write here. Sent only to api.github.com.

AI review (optional)

Adds plain-English cards and a second opinion on each fork. This sends the fork's changed code to Anthropic using your own API key, and your key is billed for it. The scan always runs regardless, and a serious scan finding blocks copying whatever the AI says. When this is off, results are labelled "pattern scan only".

Forking (optional)

Lets the results page create a public fork in your GitHub account, after a confirmation screen each time. This is the only thing the extension can write. It needs its own token that can create forks (a classic token with public_repo access works). Keep it separate from the reading token above.
